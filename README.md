# Applied Deep Learning

This repository contains my coursework for Applied Deep Learning at the University of Zurich. I use Python to train classification models and explore how to tell which predictions a model gets right and where it makes mistakes.

## What I’m working on

* Predicting passenger survival using the Titanic dataset
* Training convolutional neural networks (CNNs) on small image classification tasks
* Using confusion matrices to see which classes a model mixes up and ROC curves to explore how performance changes with the classification threshold

I add new work as I progress through the course.
